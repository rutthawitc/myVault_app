TROUBLESHOOTING
================================================================================

PROBLEM: Application won't start
SOLUTION: Run as Administrator
  Right-click executable → Run as administrator

PROBLEM: Forgot master password
SOLUTION: ❌ Cannot be recovered
  Options:
  1. Use backup of original files
  2. All encrypted files become inaccessible

PROBLEM: Out of memory error
SOLUTION: Close other applications
  MyVault already optimized for large files
  2GB RAM minimum should be sufficient

PROBLEM: Files locked by other program
SOLUTION:
  1. Close file managers
  2. Close web browsers
  3. Close all other applications
  4. Restart if necessary

FULL TROUBLESHOOTING: See DEPLOYMENT_GUIDE.md
